# UAFS AVC 

## Old Code
This is the official github repo for UAFS AVC: autonomous vehicle challenge team. 
All of the old code used in past competitions from 2024 to current is stored under the Archived directory.
Organization of the Archived directiory is very bad and will probably not be improved, but any new code from 2026-forward will be organized.

## New Codebases
All new code for 2026-2027 is under the ARKOV directory. 

The AGX_TestBench directory is for development on our bench setup for the ro-arm m3 pro (our choice of robotic arm).

UCA_homeR is code made for the homer bot provided to us by UCA: University of Central Arkansas at a workshop event.

### ARKOV
Arkov code utelized doxygen compatible comments, this allows the use of doxygen for generating html and pdf documentation for the codebase. 

Code is seperated into groups.
- SLAM
- MOVEMENT
- more....
