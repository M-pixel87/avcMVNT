# Reinforcement Learning

## Overview
Reinforcement learning involves a training a neural net to output a policy  
this policy could be things such as a target position, heading, velocity, ect  
## How this applies to AVC?  
For this avc project I will attempt to use a neural net trained with reinforcement  
learning to tell the vehicle where to drive or some other kinds of commands which  
will be determined by the neural net with the input of some of the variables we  
get from the probabalistics model aswell as the object detection ai.
