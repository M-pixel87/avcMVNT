# PID: Proportional, Integral, Derivative

## Proportional Part:
This is just a linear model, for example in controlling a car the speed that we set to would be linearly 
related to the distance, or error from the position we want to be. multiplies by some k_p const

## Integral Part: 
This integrates our error over time, multiplies it by some k_i const

## Derivative Part: 
This is the derivative of our error over time, multiplies by some k_d const

## Output:
The different parts are summed and this is defines the command for whatever process you have.
